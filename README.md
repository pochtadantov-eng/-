# Режим «Лес» для Roblox

Проект в формате [Rojo](https://rojo.space) (нужен Rojo 7.3+). Весь мир строится кодом, ассеты руками делать не нужно.

## Запуск

1. Установить Rojo (`aftman install` или плагин Rojo в Studio).
2. `rojo serve` в корне репозитория, в Studio открыть пустой Baseplate-плейс и нажать **Connect** в плагине Rojo.
3. Нажать Play. Для проверки лобби с несколькими игроками: Test → Local Server → 2+ игроков.

Либо собрать файл: `rojo build -o ForestMode.rbxl`.

## Как это работает

1. **Хаб** — круглая площадь с фонтаном, забор по кругу с воротами, за забором дорога с машинами, в небе птицы. В пустой круг заходит первый игрок и становится владельцем.
2. Внутри круга появляется барьер: изнутри выйти можно только кнопкой **«Выйти»**, снаружи зайти нельзя, пока лобби не создано или пока оно заполнено. Владелец по центру экрана выбирает карту и число игроков (1–6) и жмёт **«Создать лобби»**.
3. После создания в круг могут зайти ещё игроки, пока есть свободные места. Когда лобби заполнилось, сверху идёт таймер 10 секунд. Владелец может **пропустить** ожидание или нажать **«Начать сейчас»** раньше, не дожидаясь заполнения.
4. **Катсцена**: затемнение, грузовик с лесником в центре кузова и игроками на сиденьях по кругу едет по дороге; на месте лесник открывает задние двери и говорит «Выходите!».
5. Затемнение, и всех телепортирует в лес к костру и палаткам: вокруг холмы, горы, пещеры, поляны с цветами, деревья и камни. Цель пока одна — бегать.

## Музыка

В `src/shared/Config.luau` впиши ID треков в `HUB_MUSIC_ID` (хаб) и `FOREST_MUSIC_ID` (лес). Найти ID: Toolbox → Audio → выбрать трек → Copy Asset ID. Пока поля пустые, музыки нет.

## Структура

| Файл | Что делает |
|---|---|
| `src/shared/Config.luau` | Настройки: размер лобби, таймер, карты, координаты сцен |
| `src/shared/Remotes.luau` | RemoteEvent'ы клиент↔сервер |
| `src/server/Main.server.luau` | Точка входа, освещение |
| `src/server/Hub.luau` | Площадка и 4 круга |
| `src/server/LobbyService.luau` | Состояния кругов, владелец, вход/выход, таймер |
| `src/server/Cutscene.luau` | Грузовик, лесник, поездка, телепорт |
| `src/server/Forest.luau` | Генерация террейна, пещер, деревьев и камней |
| `src/client/Main.client.luau` | Интерфейс лобби, таймер, затемнение, субтитры |
| `src/client/Ambient.client.luau` | Музыка, птицы, машины на дороге |

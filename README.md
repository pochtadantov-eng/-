# Т-Банк — PWA

Концепт мобильного банка в стиле Т-Банка. Устанавливается на iPhone как PWA через Safari.

## Установка на iPhone

1. Включите **GitHub Pages** в репозитории:
   `Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save`
2. GitHub соберёт сайт за минуту, адрес появится там же:
   `https://<ваш-логин>.github.io/<имя-репо>/`
3. Откройте этот адрес в **Safari на iPhone** (именно Safari, не Chrome).
4. Нажмите кнопку «Поделиться» → **«На экран „Домой"»** → «Добавить».
5. На рабочем столе появится иконка «Т-Банк» — приложение запускается в полноэкранном режиме, работает офлайн.

## Файлы

- `index.html` — само приложение (HTML/CSS/JS, без зависимостей)
- `manifest.webmanifest` — манифест PWA (имя, иконки, цвета)
- `sw.js` — service worker для офлайн-кэша
- `icons/` — иконки приложения

## Обновления

После пуша новых изменений в `main` поднимите `CACHE_VERSION` в `sw.js`, иначе Safari покажет старую версию из кэша.
